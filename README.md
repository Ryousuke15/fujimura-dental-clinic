# 藤村歯科クリニック ホームページ

鹿児島市皇徳寺台・藤村歯科クリニックの公式サイト（HTML/CSS/JSのみ）。

## ページ
- `index.html` トップ
- `services.html` 診療案内（自費診療の費用・リスクを含む）
- `doctor.html` 院長・スタッフ紹介
- `access.html` アクセス・診療時間
- `contact.html` ご予約・お問い合わせ

## フォルダ
- `css/style.css` 全ページ共通のデザイン
- `js/main.js` メニュー開閉・写真の有無の判定など
- `images/` 写真（ファイル名は「画像の入れ方.md」を参照）

写真が無い枠は自動で非表示になります。URL末尾に `?photos` を付けると写真の入る場所を確認できます。

## 公開時の注意
- サーバーには `README.md` と `画像の入れ方.md` 以外をアップロードしてください。
- 診療時間を変更するときは、全ページ（ヘッダー・時間表・予約案内・フッター）を同時に直してください。
